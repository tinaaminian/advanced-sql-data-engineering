# Advanced SQL for Data Engineering

A hands-on PostgreSQL project demonstrating advanced SQL techniques commonly used in real-world data engineering workflows.

The project focuses on practical patterns for transforming, validating, reconciling, and loading data rather than isolated SQL syntax examples. It covers advanced joins, window functions, data quality, incremental processing, change detection, and dimensional modeling.


## Tech Stack

- PostgreSQL 18
- Docker
- Docker Compose
- DBeaver
- SQL
- Git / GitHub
